zbrain

zbrain is a Go-native CLI for local-first trusted memory and workspace-isolated agent context.

GO-NATIVE · LOCAL-FIRST · NO LLM REQUIRED

Get started Read the README

What it is

The shipped runtime keeps canonical OKF-style Markdown claims and immutable local evidence snapshots, builds a disposable SQLite FTS5 index, and returns trusted context JSON. It does not call an LLM or model provider.

Features

  • Workspace isolation

    Workspace-isolated memory rooted at ~/.zbrain/ or ZBRAIN_HOME.

  • Claim tiers

    OKF-style claim concepts in the axioms, mental-models, projects, and decisions tiers.

  • Claim lifecycle

    Explicit claim lifecycle: draft -> approved -> superseded|revoked.

  • Evidence snapshots

    Immutable local evidence snapshots with origin, capture time, media type, byte length, and SHA-256 metadata.

  • Lexical index

    Rebuildable per-workspace SQLite FTS5 lexical indexes.

  • Fail-closed retrieval

    Fail-closed trusted retrieval with visible ready, gap, and blocked outcomes.

  • Diagnostics

    status and doctor diagnostics for index and embedding configuration.

  • Hybrid retrieval

    Optional local hybrid retrieval through ask --embed; lexical retrieval remains the default and fallback.

  • MCP gateway

    A stdio MCP gateway via zbrain mcp serve, with an owner-pinned approval ceremony.

  • Loopback viewer

    A loopback-only read-only viewer via zbrain view.

  • Embedded assets

    Embedded runtime assets extracted by zbrain setup.

Trust and data flow

  1. evidence add copies an already-local file into an immutable evidence snapshot and records its metadata.
  2. claim draft writes an OKF claim candidate. The claim body is read from stdin; drafts are never trusted answer material.
  3. claim approve validates the claim basis and referenced evidence or supporting claims, then records verified.at, verified.by, and verified.digest.
  4. reindex scans canonical Markdown and evidence, validates trust inputs, and publishes a clean or rejected disposable index without rewriting canonical files.
  5. ask checks index freshness and the returned claim's canonical binding and trust dependencies before returning JSON. Conflicts produce blocked; no matching approved claim produces gap.

Install

go install github.com/therealtinhtute/zbrain/cmd/zbrain@latest
zbrain setup

ZBRAIN_HOME overrides the runtime root. Without it, the default is ~/.zbrain/. Use it for tests, smoke runs, and isolated experiments:

ZBRAIN_HOME=/tmp/zbrain-dev go run ./cmd/zbrain setup

Boundaries

The current slice is intentionally local and minimal: no hosted sync, no network crawling, no background service, and no model-provider integration. MCP is stdio-only, the viewer is loopback-only, and optional embeddings are local sidecars rather than a trust or availability requirement. All surfaces preserve the fail-closed runtime contract.
